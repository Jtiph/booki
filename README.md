# Booki 

Site responsive de recherche d’hébergements et d’activités permettant aux utilisateurs de découvrir des logements et services touristiques selon la ville choisie.
<img width="699" height="418" alt="Capture d&#39;écran 2026-05-21 152022" src="https://github.com/user-attachments/assets/2e0bd619-71ff-4833-bb82-90be65364bfd" />

## Features

- Intégration responsive desktop, tablette et mobile
- Recherche d’hébergements et d’activités
- Mise en page fidèle à une maquette Figma
- Interface utilisateur moderne et épurée
- Organisation des contenus avec Flexbox

## Tech Stack

- HTML5
- CSS3
- Flexbox
- Responsive Design
- Figma
- GitHub Pages
